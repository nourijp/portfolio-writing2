Choose a Dashboard Layout for Your Task

A conceptual explanation connecting a software feature to everyday work.

Audience Business application users

Adapted portfolio sample using a fictional product and scenario.

A dashboard brings related information into one view. The most useful arrangement depends on the task you are trying to complete.

Start with a question

Before adding panels, ask what you need to know when you open the application.

A support coordinator may need open requests and customer contact information. Someone reviewing project delivery may need milestones, overdue tasks, and outstanding decisions.

Choose the information that helps you make the next decision. Add other panels when the task requires them.

Use different views for different tasks

A daily overview can help you decide where to begin. A project dashboard can bring together information you need for a specific assignment.

For example, a project handover view might include the checklist, upcoming dates, and unresolved questions. Once the handover is complete, you can return to your regular dashboard.

Review what you have built

Use the dashboard during a normal work session. Notice which panels you consult and which you repeatedly scroll past.

Move the most frequently used information into view. Remove panels that do not help you complete the task.
